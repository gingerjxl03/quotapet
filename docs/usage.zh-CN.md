# 额度桌宠

## 怎么看

- 菜单栏会常驻显示 `5h 剩余% · 周 剩余%`。
- 桌面双圆环分别表示 5 小时额度和每周额度。
- 绿色表示充足，橙色表示偏低，红色表示剩余不超过 20%。
- 点击菜单栏文字可以查看重置时间和可用重置券。

## 怎么用

- 拖动桌面气泡，把它放到 ChatGPT 桌宠旁边。
- 双击桌面气泡，或在菜单栏选择“立即刷新”。
- 菜单栏里可以隐藏/显示气泡，也可以退出应用。
- 应用每两分钟自动刷新一次。

## 隐私与兼容性

- 应用只调用本机 Codex 的额度状态服务，不保存 Cookie、密码或访问令牌，也不读取聊天内容。
- 当前额度读取接口属于 Codex 的实验性本机协议。ChatGPT 更新后如果协议发生变化，应用可能需要更新。
