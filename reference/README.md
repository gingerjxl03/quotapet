# Codex app-server protocol snapshot

`codex-app-schema/` preserves the generated protocol JSON files present in the original QuotaPet development folder on 2026-09-29. These are schema definitions, not account responses or conversation records. The exact upstream revision was not recorded. They are included for historical completeness and are not required to compile QuotaPet.
